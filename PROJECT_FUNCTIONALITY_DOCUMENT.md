# EdTech Project - Full Functionality Document

## Project Overview
This project is a complete online education platform. It is built for students, tutors, and admins. It helps people learn online, teach online, and manage the whole learning system in one place.

This platform can be used for:
- Online courses
- Student enrollment
- Tutor management
- Payments
- Certificates
- Live communication
- Entry tests

---

## What This Project Does
This project works like a full EdTech website. It allows:
- Students to discover courses and learn online
- Tutors to create and manage courses
- Admins to control the platform and approve important actions

---

## Main Users
### 1. Student
A student can register, log in, browse courses, enroll in courses, study lessons, and track progress.

### 2. Tutor
A tutor can create courses, upload lessons, manage students, and track earnings.

### 3. Admin
An admin can manage users, approve tutors and courses, review payments, and monitor platform activity.

---

## Student Features
### Signup and Login
Students can:
- Create an account
- Log in with email and password
- Login using Google OAuth
- View and update their profile

### Course Browsing
Students can:
- View all available courses
- Search and browse courses
- Open course details
- See course description, tutor, price, and lessons

### Enrollment and Payment
Students can:
- Enroll in a course
- Pay for a course
- Upload payment proof for manual payment
- Wait for admin approval if required

### Learning Experience
Once enrolled, students can:
- Open course lessons
- Watch video content
- Read PDF lessons
- Mark lessons as completed
- Track their progress

### Reviews and Ratings
Students can:
- Leave reviews for courses
- Rate courses
- See feedback from other learners

### Certificates
After completing a course, students can:
- Receive a certificate
- View their certificate
- Share or verify it

### Sessions
Students can:
- Book one-on-one sessions with tutors
- See their session history
- Manage their booking requests

### Entry Tests
Students can:
- View entry tests
- Unlock paid tests after approval
- Start the test
- Submit answers
- See results and explanations

### Community and Chat
Students can:
- Join the community section
- Send messages
- Chat with others
- Receive notifications

---

## Tutor Features
### Tutor Registration and Profile
Tutors can:
- Sign up as tutors
- Complete their profile
- Manage their public profile

### Course Creation
Tutors can:
- Create new courses
- Add course title, description, price, and thumbnail
- Add sections and lessons
- Publish or unpublish courses

### Lesson Management
Tutors can:
- Upload video lessons
- Upload PDF lessons
- Remove lessons if needed
- Organize course content

### Student Management
Tutors can:
- See enrolled students
- Manage course progress
- View students for each course

### Session Management
Tutors can:
- View booked sessions
- Accept or manage appointments
- Track their teaching schedule

### Earnings
Tutors can:
- View their earnings
- Track payment-related information

---

## Admin Features
Admins can:
- View overall platform statistics
- Manage all users
- Ban or unban users
- Approve or reject tutor accounts
- Approve or reject courses
- Feature important courses
- Review payments and payment requests
- View revenue reports
- Manage platform settings
- Review entry test unlock requests

---

## Payment Features
The platform supports payment-related actions such as:
- Course purchase
- Manual payment proof upload
- Admin review of payment requests
- Revenue tracking
- Payment status management

This makes the system more secure and organized for both students and admins.

---

## Communication Features
The platform includes real-time communication tools such as:
- Chat system
- Community messages
- Notifications

These features help users stay connected, receive updates, and interact with the platform more easily.

---

## Certificate Features
The platform can:
- Generate certificates after course completion
- Store certificate information
- Display certificate details to users
- Support certificate verification

## Entry Test Features
The platform also supports skill and placement testing. Students can:
- Take entry tests
- Access free or paid tests
- Request access to paid tests
- Receive approval from admin
- Start and submit tests
- View results

## How the System Works
### For Students
1. Register or log in
2. Browse courses
3. Enroll in a course
4. Pay or upload payment proof
5. Study course content
6. Track progress
7. Get certificates and complete learning goals

### For Tutors
1. Sign up as a tutor
2. Create a course
3. Add lessons
4. Publish the course
5. Manage students and sessions
6. Track earnings

### For Admins
1. Log in to admin panel
2. Review new tutors, courses, and payments
3. Approve or reject requests
4. Monitor platform activity
5. Maintain system quality and security
